# PerkOS Grok Plugin

Grok Bot plugin for **PerkOS Floor**.

A regular user invites *their* Grok Bot from Floor **Settings → Grok Bot → Invite my Grok Bot**, copies the unique prompt, and pastes it here once. The plugin connects **outbound** to PerkOS Transport. Floor never calls the Bot cloud.

```
Floor Settings (copy prompt)
  → paste into Grok Bot
  → this plugin
  → wss://transport.perkos.xyz/a2a
  → heartbeat ready
  → Floor POST /agents/:id/task
```
